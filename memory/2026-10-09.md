### Diagnosis (live evidence)
- GSC Pages (live read, last update 10/3): 382 indexed / 409 not indexed — buckets: robots-blocked 210, **alternate-canonical 146**, noindex 50, crawled 2, redirect 1 (validation "Started"). <!-- project: github.com/ericzhoun/lectio -->
- Opened the bucket drilldown: **every example URL is `?lang=en`** (`/library/proverbs-30-8-9?lang=en`, `/about?lang=en`, `/topics/protection?lang=en`, …). Old validation for the bucket ran 9/30→failed 10/4. <!-- project: github.com/ericzhoun/lectio -->
- These are English copies of pages that already exist at the bare (self-canonical) URL: Google treats `?lang=en` as a redundant designated alternate and skips it. Root cause: the site emitted `?lang=en` links site-wide (nav switcher + every content link: 182 on /library alone, 32 on /topics/anxiety), so Google kept discovering the twins. The 9/28 decision ("?lang=en switcher URLs are expected alternates, no action") was wrong for indexing — the URLs were indexable but permanently alternate. <!-- project: github.com/ericzhoun/lectio -->

### Fix (code, commit 73fd1bb + 3c80d60 + 2b0e865)
- New link policy: English links are **bare** (canonical); only Chinese carries `?lang=zh`. `langHref()` in `src/lib/i18n.ts` applies it; `langSwitchHref(astro, target, currentLang)` keeps exactly one flip link (`?lang=en`) on zh pages so readers with the zh cookie can still reach English. <!-- project: github.com/ericzhoun/lectio -->
- Middleware (`src/middleware.ts`): any non-zh `?lang` on GET/HEAD non-API pages → **301** to the canonical path with all other params preserved, setting `lang=en` cookie for the `en` alias (readers stay in English; crawlers only see the 301). `/api/*` untouched (`/api/tts?lang=en` still 200). POST not redirected (would be rewritten to GET). <!-- project: github.com/ericzhoun/lectio -->
- Auth routes default to English when no lang param (`resolveLang` in google/start; `!== 'zh'` checks in login/callback). Daily email link for en readers drops `lang=en`. llms.txt updated. <!-- project: github.com/ericzhoun/lectio -->
- Tests: new `langHref` + `?lang=en` retirement suites; all 598 pass (only pre-existing assistant-loop OPENAI_API_KEY collection failure), astro check 0 errors, build green. <!-- project: github.com/ericzhoun/lectio -->
