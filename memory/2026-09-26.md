# 2026-09-26

## SEO: aligned with inspire's canonical/hreflang fix

GSC's "Alternate page with proper canonical tag" work on inspire (dramatherapy.us) was
ported here. Enjoyhim.org was already in decent shape — zh pages self-canonicalized and
the middleware 308s trailing slashes — but three gaps remained:

- `Layout.astro` chose the canonical from the cookie-resolved `lang`; now it uses the
  URL's own `?lang=` param via `src/lib/seo.ts` (`canonicalHref`, `hreflangAlternates`,
  `SITE_URL`, `normalizePath`) so crawlers get a deterministic canonical. Same policy
  module as inspire, different SITE_URL. Tests: `src/lib/__tests__/seo.test.ts`.
- Sitemap now lists BOTH language variants as their own `<url>` entries (316 total:
  158 en + 158 zh) and adds `hreflang="x-default"`; the xhtml:link cluster mirrors the
  on-page tags exactly.
- `?lang=en` links (from the language switcher) self-canonicalize to the bare path —
  those are expected to keep showing as "Alternate page" in GSC; that status is benign.

Verified: `npm test` (12 new seo tests pass; `assistant-loop.test.ts` fails at collection
on missing OPENAI_API_KEY — pre-existing on unmodified main), `astro check` clean,
`npm run build`, then `npm run preview` + curl: zh self-canonicals, cluster correct,
`/pricing/` → 308 via middleware, all pages full bodies.

## Lesson: middleware is fine on this stack

Inspire's empty-body scare was misattributed to middleware; the real cause was a
frontmatter `ReferenceError` (see inspire memory 2026-09-25 correction). Lectio's own
production middleware (HTTPS 301, trailing-slash 308, vid/ab cookies, noStore) plus the
re-added inspire middleware prove `src/middleware.ts` works fine on astro +
@astrojs/cloudflare. Pattern worth copying here when editing .astro frontmatter:
`npx astro check` catches removed-but-still-referenced consts that `astro build` won't.

## Gotcha: relative paths + shell cwd

Ran a `sed -i '' src/layouts/Layout.astro` while the shell cwd was still the inspire
repo — it edited inspire's file instead of lectio's (harmless no-op there, but a real
risk). Use absolute paths for sed/cp against the other repo, or cd first.
