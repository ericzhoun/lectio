结论

字段完整、无重复行；last_login_at 每次登录刷新，created_at 永不变更；密码账号被关联后原密码哈希原样保留；审计可通过 getUserByEmail / listUsers 或 wrangler d1 execute 直接查询。

安全检查

  • client_secret 仅从环境变量读取，未硬编码、未入库（callback.ts）。
  • state：24 字节随机 base64url，httpOnly Cookie 限定回调路径、10 分钟过期、常量时间比较、用后即删。
  • 未验证邮箱的 Google 账号直接拒绝，不能冒名关联已有邮箱。
  • Google 专属账号密码哈希为空串，PBKDF2 校验恒为 false（单测覆盖）。
  • 可选加固（非本期）：id_token JWKS 签名校验、登录限流、关联通知邮件。

兼容性与说明

  • 登录流程纯服务端渲染 + 标准链接/表单跳转，不依赖 JavaScript，现代浏览器与禁用 JS 环境均可完成。
  • 登录/注册/账户页响应式沿用站点既有 CSS（≤700px 单列布局）。
  • 说明：未在真实浏览器矩阵逐一截图回归；如需可后续接入 Playwright。
  • 生产待管理员一次性配置：Google Cloud Console 创建 OAuth 客户端（回调 https://<域名>/api/auth/google/callback）+ wrangler secret put GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET。配置前 OAuth 入口优雅返回“暂未配置”。
