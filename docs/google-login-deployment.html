Google 登录 · 部署与交接文档

Inspire（Astro 7 SSR + Cloudflare Workers + D1 + KV） · 2026-08-27

配套文档：《Google 登录功能 · 运行/检查结果报告》

1. 环境变量

变量必填说明
SESSION_SECRET是（已有）会话签名密钥，保持现状
GOOGLE_CLIENT_ID是Google Cloud Console OAuth 客户端 ID
GOOGLE_CLIENT_SECRET是用 wrangler secret put 设置，勿入库
GOOGLE_REDIRECT_URI建议默认按请求来源自动推导；多域名/反代才需显式设置
GOOGLE_AUTH_URL / GOOGLE_TOKEN_URL / GOOGLE_USERINFO_URL否仅本地测试指向模拟 IdP；生产必须不设置

2. Google Cloud Console 配置（一次性）

  1. 打开凭据页

    console.cloud.google.com/apis/credentials

  2. 配置 OAuth consent screen

    External 类型，填应用名与支持邮箱；Testing 状态仅白名单账号可登录，正式开放需 Publish。

  3. 创建 OAuth client ID（Web application）

    Authorized redirect URI 精确填写：https://inspire.joechenst.workers.dev/api/auth/google/callback；每个自定义域名各加一条。

  4. 写入 Workers 密钥

    npx wrangler secret put GOOGLE_CLIENT_ID 与 npx wrangler secret put GOOGLE_CLIENT_SECRET

3. 数据库初始化与迁移

无需手工迁移：首次请求自动建表并对旧库逐条 ALTER（幂等）。如需手工预执行：

npx wrangler d1 execute inspire-readings --remote --command "ALTER TABLE users ADD COLUMN google_id TEXT;
ALTER TABLE users ADD COLUMN name TEXT;
ALTER TABLE users ADD COLUMN avatar_url TEXT;
ALTER TABLE users ADD COLUMN last_login_at DATETIME;
CREATE UNIQUE INDEX IF NOT EXISTS idx_users_google_id ON users(google_id);"

资源清单

D1：inspire-readings（2873b281-1d7c-4a82-8649-a91d912bbb0f，沿用）· KV：SESSION（8c7ba8cc166749d49512d17cd856b45c，已创建；新环境执行 wrangler kv namespace create SESSION 后把 id 填入 wrangler.jsonc）。

4. 部署步骤

方式操作
A · Workers Builds（已启用 CI）提交并推送 main；构建命令 npm run build，部署命令 npx wrangler deploy，进度见 Dashboard → Workers → inspire → Deployments
B · 本机手动npm install && npm run build && npx wrangler deploy（需已 wrangler login）

注意：只维护根 wrangler.jsonc；dist/server/wrangler.json 由构建生成，勿手改。部署失败的常见原因即“改了根配置但未重新 build”。

5. 部署后冒烟清单

curl -s -o /dev/null -w "%{http_code}\n" https://inspire.joechenst.workers.dev/                 # 期望 200
curl -s https://inspire.joechenst.workers.dev/login | grep -c "/api/auth/google/start"          # 期望 ≥1
curl -s -o /dev/null -w "%{http_code} %{redirect_url}\n" \
  https://inspire.joechenst.workers.dev/api/auth/google/start
# 未配密钥 → 302 /login?error=config；配好后 → 302 accounts.google.com
npx wrangler d1 execute inspire-readings --remote \
  --command "SELECT email,google_id,created_at,last_login_at FROM users ORDER BY created_at DESC LIMIT 10"

浏览器完成一次真实 Google 注册 → 登出 → 再登录，SQL 确认仍一行且 last_login_at 更新。

6. 回滚

  • 代码：Dashboard → inspire → Deployments 选历史版本 Rollback（秒级）；或 git revert 后重新部署。
  • 数据库：本次全部为增量变更（新增可空列 + 索引），不删不改既有列；旧代码忽略新列，无需回滚。如必须移除索引：DROP INDEX IF EXISTS idx_users_google_id;
  • 密钥：泄露时在 Google Console 重置，并重跑 wrangler secret put。

7. 本地开发与测试

npm install
npm test                       # 43 个单元测试
npm run build
npx wrangler dev --port 8787   # 读 .dev.vars；D1/KV 本地模拟
# 另开终端：node scripts/mock-google-server.mjs（模拟 Google，:9000）
node scripts/e2e-google-login.mjs http://localhost:8787 http://127.0.0.1:9000
node scripts/e2e-google-link.mjs  http://localhost:8787 http://127.0.0.1:9000

模拟 IdP 控制：/auth?deny=1 模拟取消；POST /__toggle-fail 切换 500 故障；POST /__set-user 切换测试档案。本地 .dev.vars 需含 GOOGLE_* 指向 127.0.0.1:9000 与占位 client_id/secret。
